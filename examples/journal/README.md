# 可复现的 MoonBit 库示例

在仓库根目录运行，不需要浏览器、账号或网络推送服务：

```sh
moon run examples/journal --target js
```

预期输出：

```text
Pet: 小橘
Diaries: 2
2026-10-14: 4.125 kg
2026-10-15: 4.2 kg
Backup roundtrip: true
小橘：我们已经 3 天没留下新回忆啦。
```

示例完成档案创建、早晚日记、精确体重解析、日期排序、JSON 备份往返和问候文案生成。它只在内存中运行，不写入真实手帐。问候输出不是系统推送，日记中的文字也不代表结构化用药管理。
