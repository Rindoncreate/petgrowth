# 评委复现步骤

## 命令行验收

安装 MoonBit CLI 和 Node.js 后，在仓库根目录运行：

```sh
moon update
node scripts/verify.mjs
```

此命令执行格式检查，分别对 JS、Wasm GC、Wasm 做检查与测试，运行并核对库示例的输出，构建 PWA、检查静态资源并生成 Mooncakes 源码压缩包。源码包位于 `_build/publish/`。首次运行需要网络下载依赖。

## 网页体验（约三分钟）

```sh
node scripts/build.mjs
node scripts/serve.mjs
```

1. 打开 `http://127.0.0.1:4173/?demo=1`。页面右上角显示「示例手帐」。点击上下纸卡或底部箭头翻阅，点击当前卡片看详情。
2. 点底栏「成长」，看按日期左右排列的体重照片；点右上角折线图按钮，核对六次体重的数值与模样。
3. 点中间记录按钮，选择日期，写一段日记，可选一张本机照片，保存。页面退出示例，显示自己的手帐；刷新后仍存在。
4. 再记一次 `4.125` kg 的体重，刷新后在成长页查看数值。输入 `0` 或 `4.1234` 时应显示校验提示，保留输入表单。
5. 右上角「更多」进入档案，设置名字与日期。可以导出 JSON 备份，再在另一浏览器导入。
6. 在档案开启「宠物问候」，进入提醒页看文案。该版本没有系统后台通知，页面对此有明确说明。

示例数据不会写入真实手帐。演示图片为原创 AI 素材；上传透明 PNG 保留透明度，不代表已支持自动抠图。

## 验收边界

首版可交付为单宠物、浏览器本地保存的应用和可复用 MoonBit 核心。多宠物、用药表格、家人共享、iCloud、自动抠图、系统推送、App Store 上架不属于已完成功能。iPhone Safari 安装与离线重开尚待真机验证。
