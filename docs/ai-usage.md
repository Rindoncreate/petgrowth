# AI 辅助与作者负责范围

本项目使用 Codex 辅助需求分析、MoonBit 与网页实现、测试补充、构建排错和技术文档整理；示例幼犬图片使用 imagegen 生成。没有集成在线大模型服务，应用内问候是可测试的 MoonBit 规则文案，不是模型生成或真实推送。

参赛者提出了养宠记录的实际需求，并决定产品范围及后续方向。当前代码包含 AI 辅助内容；作者应在提交前亲自理解并运行下列路径：

1. `pet.mbt`：日记与体重如何保存；为什么用整数克；排序与备份校验如何工作。
2. `app/main.mbt` 与 `app/persistence.mbt`：消息如何更新状态；保存失败为什么保留草稿。
3. `app/views.mbt`：纸卡、照片成长轴与 SVG 折线如何读取核心记录。
4. `examples/journal/` 与测试：如何在不打开浏览器的情况下复现核心功能。

AI 编写或整理的技术文档不替代人工申报书。赛事要求的一页 Markdown 申报书由参赛者本人撰写；不把本说明、README 或自动生成的文字冒充人工申报书。

参考范围与素材来源见 [设计说明](design-reference.md)。未来功能（多宠物、结构化用药、共享、iCloud、抠图、推送）不作为首版已完成成果申报。
